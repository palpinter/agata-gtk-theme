# Agata for other apps

Color schemes that match the four Agata themes, so other apps blend in with GTK windows and
the GNOME Shell. Each app has its own folder with the schemes and installation steps.

| App | Folder | Variants |
|---|---|---|
| Alacritty | [`alacritty/`](alacritty) | Nord Dark, Nord Light, Gruvbox Dark, Gruvbox Light |
| Ghostty | [`ghostty/`](ghostty) | Nord Dark, Nord Light, Gruvbox Dark, Gruvbox Light |

## Variants

| Variant | Background | Accent | Notes |
|---|---|---|---|
| Agata Nord Dark | `#303744` | `#81a1c1` | Standard Nord colors. Bright black is lifted to Nord's comment gray `#616e88` so it stays readable. |
| Agata Nord Light | `#eceff4` | `#81a1c1` | Nord hues darkened to at least 4.5:1 contrast (bright colors 3:1). The plain Nord colors reach only about 2:1 on a light background. |
| Agata Gruvbox Dark | `#282828` | `#83a598` | Standard Gruvbox colors. Black is lifted to `#3c3836` so it differs from the background. |
| Agata Gruvbox Light | `#f9f5d7` | `#458588` | Gruvbox colors in light-theme order: black is dark, white is light, and the normal colors are the readable "faded" Gruvbox shades. |

## `palette.json`

[`palette.json`](palette.json) holds all the colors for every variant. The app schemes are
generated from it, and you can also read it to theme an app that is not covered here.

- `ui`: colors shared with the GTK theme: `background`, `foreground`, `surface` (views and
  lists), `elevated` (cards and popovers), `accent`, `accent_foreground` and `accent_text`.
- `terminal`: terminal roles: text, cursor, selection, status bar and search matches.
- `ansi`: the 16 ANSI colors (`normal`, `bright`, optionally `dim`).
- `min_contrast`: optional readability targets for the ANSI colors on the background.

## Regenerating and adding apps

Every file in the app folders is generated by `tools/gen-app-themes.py`. Do not edit those
files by hand. Change `palette.json` and run the script. It also checks that:

- the `ui` colors still match the GTK themes (the libadwaita palette block in
  `themes/*/gtk-4.0/gtk.css`);
- every `min_contrast` target is met.

If a check fails, the script writes nothing. With `--check`, it exits with status 1 when any
file is out of date.

To add an app:

1. Write a `render_<app>(name, variant)` function in the script.
2. Register the function in `APPS` with its output path.
3. Add `extras/<app>/README.md` with installation steps.
4. Add a row to the table above.
