# Agata terminal color schemes

Color schemes for **Alacritty** and **Ghostty** that match the four Agata themes. Each scheme
uses the theme's own background and accent colors, so the terminal blends in with
GTK windows and the GNOME Shell.

| Scheme | Background | Notes |
|---|---|---|
| Agata Nord Dark | `#303744` | Standard Nord colors. Bright black is lifted to Nord's comment gray `#616e88` so it stays readable. |
| Agata Nord Light | `#eceff4` | Nord hues darkened to at least 4.5:1 contrast (bright colors 3:1). The plain Nord colors reach only about 2:1 on a light background. |
| Agata Gruvbox Dark | `#282828` | Standard Gruvbox colors. Black is lifted to `#3c3836` so it differs from the background. |
| Agata Gruvbox Light | `#f9f5d7` | Gruvbox colors in light-theme order: black is dark, white is light, and the normal colors are the readable "faded" Gruvbox shades. |

## Alacritty

Copy the files and import one of them in `~/.config/alacritty/alacritty.toml`:

```bash
mkdir -p ~/.config/alacritty/themes
cp extras/terminal/alacritty/*.toml ~/.config/alacritty/themes/
```

```toml
[general]
import = ["~/.config/alacritty/themes/agata-nord-dark.toml"]
```

Remove any `[colors]` sections from `alacritty.toml` itself. Settings in the main file take
precedence over imported ones.

## Ghostty

Copy the files to Ghostty's theme directory:

```bash
mkdir -p ~/.config/ghostty/themes
cp extras/terminal/ghostty/Agata-* ~/.config/ghostty/themes/
```

Then set the theme in `~/.config/ghostty/config.ghostty`. Use a fixed theme:

```
theme = Agata-Nord-Dark
```

Or follow the system light/dark preference:

```
theme = light:Agata-Nord-Light,dark:Agata-Nord-Dark
```

Reload the configuration (default keybinding: <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>,</kbd>) or open a new window.

## Regenerating

The files are generated by `tools/gen-terminal-themes.py`. Do not edit them by hand. Change the
palettes in the script, then run it. The script checks that the background and accent colors
still match the GTK themes. `--check` exits with status 1 if a generated file is out of date.
